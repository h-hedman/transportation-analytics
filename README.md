# Transportation Analytics

Public transportation analysis projects covering statistical methods, capacity, utilization, and operational questions. Each project has its own documentation and working directory.

## Projects

| Project | Scope |
| --- | --- |
| [NCFO ferry capacity and utilization](ncfo-ferry-capacity-analysis/) | Draft analytical framework, data preparation, and analysis of ferry capacity and utilization using National Census of Ferry Operators data. |

## Working with this repository

```sh
git clone https://github.com/h-hedman/transportation-analytics.git
cd transportation-analytics/ncfo-ferry-capacity-analysis
```

Run project scripts from their documented working directory. See the [NCFO README](ncfo-ferry-capacity-analysis/README.md) for scope and source documentation.

This repository contains selected public work. It is not a mirror of internal working directories or unpublished drafts. Project-specific licenses remain alongside their projects.

## Organization

The original `ncfo-ferry-capacity-analysis` repository was renamed to `transportation-analytics` and its files moved into the project folder on October 24, 2026. Git history is retained.
